# 🌌 Cosmic Resume — Software Engineer
### Advanced 2026 HTML/CSS/JS Portfolio Resume

## ✦ Features
- **Live Starfield Canvas** — Animated stars, nebulae & shooting meteors
- **Typewriter Effect** — Cycling role titles
- **Custom Cursor** — Glowing neon cursor with particle trail
- **Glassmorphism Cards** — Frosted glass UI with hover glow
- **Skill Bars** — Animated on scroll
- **Count-up Stats** — Numbers animate into view
- **Scroll Reveal** — Staggered entrance animations
- **Parallax Layers** — Nebula & grid shift on scroll
- **Scan Line** — Cyberpunk HUD feel
- **Loading Screen** — Animated progress bar
- **Fully Responsive** — Works on all screen sizes

## 🚀 How to Use
1. Open `index.html` in any modern browser
2. No build tools needed — pure HTML/CSS/JS
3. Replace "Aryan Sharma" with your name throughout
4. Update links, projects, skills, and experience
5. Customize colors in `:root` CSS variables

## 🎨 Customization
Edit these CSS variables in `css/style.css`:
```css
:root {
  --c1: #00d4ff;   /* neon cyan — primary accent */
  --c2: #b44fff;   /* neon purple — secondary accent */
  --c3: #ff6b35;   /* neon orange */
  --c4: #00ff9d;   /* neon green */
  --c5: #ffd700;   /* gold */
}
```
